# Interior reconstruction
InteriorReconstruction.js — independent procedural components and cabin presets.
TextureMapping.js — local approved photo crop to UV texture.
TextureEditor.jsx — selection, crop, brightness, rotation, repetition and apply.
Estimated geometry, no photographic accuracy claim.

InteriorStructure.js: V6.3 measured dashboard/steering/carpet anchors, connected console, seat supports and camera poses; retains curved stock roof. InteriorReconstruction.js: reference-guided instrument/console details. Real photographs 01, 05, 07, 09, 13, 23–25, 29, 41–45, 47, 56 inform material and layout; not a calibrated scan.
