# Vectra Virtual Lab — V1 (desenvolvimento)
Laboratório virtual independente para Chevrolet Vectra CD 2.2 2000.
Não publicado. A geometria inicial é um sedã esquemático original, não um Vectra fiel. Importe GLB autorizado para trabalhar com o modelo real.

## Executar
```sh
cd code
npm ci
npm run dev -- --port 5173
npm test
npm run build
```
Abrir http://localhost:5173/VectraAutomation/ . Node 22 recomendado.
Ver documentação em documentation/. Inventário Google privado: conexão por OAuth em memória, configuração local pelo operador. Não inserir credenciais no Git.
