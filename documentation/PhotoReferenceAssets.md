# Acervo fotográfico — lote 01
Seis fotografias fornecidas pelo responsável para inclusão no GitHub e no site. Classificação visual manual, não inferência automática. Catálogo único: code/src/lib/photo-reference/ReferenceCatalog.json.
- Acervo fonte: documentation/asset-source/acervo-fotografico/{interior,exterior}; JPEGs byte a byte preservados; fora do build Pages. GitHub é público e os originais estão versionados por solicitação explícita.
- Publicação: code/public/assets/acervo-fotografico/{interior,exterior}/{webp,png}. WebP com lado máximo de 600 px, qualidade 84, Lanczos; PNG em resolução integral, pixels RGB iguais à decodificação do JPEG, sem metadados adicionais. Nenhuma melhoria artificial, recorte ou mudança de conteúdo. Identidade por SHA-256, dimensões, tamanho, Git blob hash registrados no catálogo.
- Direitos: publicação solicitada pelo responsável; autoria e licenças de terceiros não confirmadas. As referências não são automaticamente autorizadas para o editor de texturas; imagens e placas não são usadas como identificação do carro do proprietário. Novas importações continuam locais, privadas e separadas.
- LCR Asset Organization Standard v1.2 consultado no Drive. Organização por página e domínio, depois formato. O PNG só é solicitado ao abrir a ampliação ou baixar. WebP lazy loading. A pasta temporária de transferência não integra o produto final.
