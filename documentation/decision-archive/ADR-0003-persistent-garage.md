# ADR-0003 — Local versioned garage and constrained environments
Status: implemented, pending gate. Use IndexedDB version 2, optimistic compare-and-write revisions, debounced autosave, independent records referencing immutable stock GLB. JSON backup for stock; no paid cloud. Central camera constraints with bounded ray from target, dedicated cabin range, closed procedural environments and instancing. Alternatives: localStorage (quota and nontransactional), cloud (cost and permissions), physics engine (additional dependencies). Reversible by Git; local models remain separate from gallery and inventory. See PersistentGarageV4.md for limitations.
