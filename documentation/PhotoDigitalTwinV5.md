# V5 Photo Reference Library
Stage 1: local-only IndexedDB database separate from garage and virtual gallery. SHA-256 identity, original bytes preserved, WebP thumbnail, multiple semantic categories, human review, rights and origin, manifest JSON with matched hashes. ZIP: bounded central-directory parser, no extraction to filesystem, no scripts, no ZIP64/encryption; stored or browser deflate-raw. Manifest metadata never auto-approves rights. Original JPEG/PNG/WebP shown only on demand. Private EXIF stays in local original, thumbnails reencoded. No cloud or publication. Photos from prompt not available in mounted files or Drive search; no assertion of actual reference ingestion. Next stage: wire semantic selection into viewer.
