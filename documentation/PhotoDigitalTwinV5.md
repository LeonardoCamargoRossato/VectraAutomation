ZIP: bounded central-directory parser, no extraction to filesystem, no scripts, no ZIP64/encryption; stored or browser deflate-raw. Manifest metadata never auto-approves rights. Original JPEG/PNG/WebP shown only on demand. Private EXIF stays in local original, thumbnails reencoded. No cloud or publication. Actual reference comparison blocked by missing photos. Browser native image decoding, Canvas, IndexedDB and Three.js only. Blender executable unavailable locally. Existing V2 research informs non-destructive modeling; neural methods not run. No external weights, APIs, or cost. Future: calibrated owner photos, Blender UV/mask/perspective, official GLB validator for exported meshes, device benchmark, complete backup containing references.
